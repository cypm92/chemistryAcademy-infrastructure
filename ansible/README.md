# Ansible

Esta capa dejará un Ubuntu recién instalado listo para ejecutar K3s de forma idempotente: usuario administrador, acceso SSH por clave, actualizaciones, cortafuegos, dependencias y configuración de K3s.

El inventario real de producción contiene la IP del VPS y no se versiona. Copiaremos un ejemplo sin datos sensibles cuando se implemente esta tarea.
